# Vega OS demo app

## Install Development Tools
installing the Vega SDK and configuring tools for app development. 

https://developer.amazon.com/docs/vega/0.22/setup-overview.html

## Import Third-Party Libraries
Use the Vega Module Resolver Preset (VMRP) to import third-party libraries with their Vega-platform ported equivalencies.

https://developer.amazon.com/docs/vega-api/0.22/vega-module-resolver-preset.html

then run
```bash
npm install
``` 

## Configure to Run
Use Vega Virtual Device or Fire TV Stick to run your Vega apps

https://developer.amazon.com/docs/vega/0.22/run-apps.html#vvd-tab

## Interactive Debugging
Debug Vega apps and Turbo Modules with Vega Studio through GDB (GNU Debugger). Vega Studio provides built-in debugging capabilities that use GDB for native code debugging

https://developer.amazon.com/docs/vega/0.22/debugger.html
